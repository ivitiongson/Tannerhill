Sort only. No reply is drafted or sent.

Load a message or type one, then press "Sort this message". The checks are fixed keyword rules written in JavaScript, not AI.

What this page does

  • Shows the last sort (), joined with each message from sources/.
  • Recalculates waiting time and days open every time the page opens.
  • Lets a person close or reopen a case. Closes are saved in this browser only.
  • Has a keyword tester that sorts one message using fixed rules from CLAUDE.md.

What it never does

  • Never drafts, suggests, queues or sends a reply. A person writes every reply.
  • Never approves or denies a warranty claim, return or refund.
  • Never changes an order, a refund, a price or a source file.
  • Never closes a case by itself, and never reassigns an owner.
  • Hides card numbers and security codes found in messages.

When it is not sure

  • It writes "UNSURE: <reason>" instead of picking the most likely answer.
  • If the sources don't answer something: "UNSURE: not in sources".
  • If the customer says they wrote before but that email isn't in the pack: "UNSURE: earlier emails not in pack, real wait is longer".

The clock starts at the customer's first email after our last reply (same order number or same sender) and stops at our first reply. With no reply it runs to now. Threats, repeat and upset customers go in Flags, never in Urgency.

Case opened and days open

  • Case opened = the customer's earliest email in the same conversation found in sources/ (ET).
  • Days open = calendar days (weekends included) from Case opened to Closed date, or to now if still open. One decimal place.
  • Only a person closes a case, by picking "Closed by" and "Closed date".

Missing info (D08-05, before anyone decides a claim)

  • Warranty: order number (or name + delivery ZIP), when it arrived, photos (fault + whole item; cooking surface for cast iron), what happened in their words (for cast iron, how it was washed and stored).
  • Return: delivery date; unused and in original packaging. Amazon orders follow Amazon's window.
